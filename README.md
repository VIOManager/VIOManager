# VIOManager

> 黑龙江科技大学科创团队协作管理平台（泓海版）

以**学期**为生命周期的团队协作管理平台，覆盖成员档案、比赛管理（比赛 → 组队 → 材料 → 成果）、项目管理、排班调度、绩效统计、技术交流、知识库与 AI 智能助手。

## 三端架构

| 端 | 角色 | 权限范围 |
|----|------|---------|
| 超级管理员端 | 平台总管理员 | 全平台数据 + 学期切换 + 系统配置 + 权限调整 |
| 部门管理员端 | 子组织负责人 | 本部门（子组织）数据 + 部门内审批 |
| 普通学生端 | 团队成员 | 自己参与的赛队 / 项目 / 排班 / 材料 / 成果 |

## 核心概念

- **学期**：一切业务数据的顶层维度
- **子组织**：按工作性质/区域划分（数媒协会、数媒二楼等），是权限边界、排班与绩效的独立单元
- **赛队**：比赛的参赛单位，组队/加人走部门管理员审批
- **项目**：独立于赛队，归项目所有人个人，可被多个赛队挂载参赛

## 技术约束（来自 PRD）

- 存储：MySQL + MinIO（图片/文件对象存储）
- 认证：JWT + BCrypt
- AI：本地优先（Ollama 等），可切换任意 OpenAI 兼容 LLM；前端入口默认停用
- 部署：Docker Compose 6 容器，对外端口 8088，支持 1Panel 导入
- 安全：项目文件强制病毒检测；身份证号/证件照加密存储；下载审计
