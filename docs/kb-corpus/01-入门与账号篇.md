# 平台使用指南-入门与账号篇

本篇介绍平台的整体面貌、账号从哪里来、怎么登录、遇到常见报错怎么办。第一次使用平台请先读本篇。

## 平台是干什么的

这里是学校科创团队的协作管理平台，以学期为周期运转。比赛报名、组建赛队、提交材料、申报成果、项目管理、值班排班、周报绩效、知识库、AI 助手都在这一个平台里完成。

平台有三种角色，各自看到的范围不同：

- 超级管理员：管理全平台，包括学期切换、组织架构、系统配置。
- 部门管理员：通常是各协会或工作室的负责人，只管理本部门及其下属组织的人和事。
- 普通学生：大部分功能的参与者——建队、交材料、写周报、用 AI 助手查自己的信息。

## 账号从哪里来

平台不开放自由注册，账号由管理员统一开通，来源有两种：

1. 管理员在人员档案里为成员绑定账号：登录名默认是学工号，初始密码 abc123。
2. 管理员批量导入人员 Excel 时自动建号：登录名同样取学工号列，初始密码 abc123。

首次登录会强制要求修改密码，改完才能进入平台。如果忘记密码，找本部门管理员或超级管理员重置，重置后回到初始密码状态，下次登录再改一次新密码。

## 登录与锁定

用登录名和密码在登录页登录。为了防撞库，同一账号连续输错密码 5 次会被锁定 15 分钟，锁定期间即使密码正确也登不进来，到点自动解锁，不需要找人处理。

登录成功后平台用令牌维持会话，长时间不操作或过期后需要重新登录。

## 常见报错速查

- 提示未登录或登录过期：会话失效了，重新登录即可。
- 提示无权限（403 或 code 1003）：这个功能或这条数据不在你的角色和数据范围内。例如学生访问管理端接口、部门管理员查看其他部门的数据。
- 提示资源不存在（code 1004）：访问的东西不存在或已被删除，检查一下链接或编号。
- 问 AI 助手提示问得太快：触发了限流，等页面提示的秒数后再问。

## 各功能入口在哪

登录后按菜单进入对应模块：人员档案、组织管理、学期管理在基础数据区；比赛、赛队、材料、成果、项目在赛事主线区；排班、绩效在日常事务区；知识库和 AI 助手在辅助区；需要你处理的审批事项在审批中心的待办里。

具体每个功能怎么用，看本系列对应篇目：组队篇、材料篇、成果篇、项目篇、排班与课表篇、绩效周报篇、AI 助手使用篇等。
