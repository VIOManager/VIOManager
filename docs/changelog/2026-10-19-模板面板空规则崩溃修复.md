# 2026-10-19 B 线修复：模板管理"新建模板"点了没反应

> 报障：比赛管理 → 模板管理 → 点"新建模板"没有任何反应。
> ⚠️ B 线模块（TemplatePanel.vue），组长指派修，开 PR 时一并报备。

## 一、根因（两层叠加）

**数据层**：`R__demo_data.sql` 种子模板 401（软件类竞赛通用模板）只插了 `id/name/status/sort_no` 四列，`default_rules` 为 NULL → T01 列表接口返回 `defaultRules: null`（后端 `toVO` 忠实映射 `parseJson(null)`→null，curl 实测确认）。

**前端崩溃点**：`TemplatePanel.vue` 表格行模板裸取 `t.defaultRules.memberLimit`——对 null 取属性抛 TypeError，Vue 渲染管线中断，面板从此"僵尸化"：

- 列表行渲染不出来（表头在、0 行）
- 空态提示"暂无模板"也不出现（同一次渲染被打断）
- **点"新建模板"：click 处理器正常执行 `dialogVisible=true`，但随后的重渲染在同一处抛错 → 弹窗永远不出现**——即用户体感"点了没反应"

创建比赛弹窗的模板下拉只用 id/name 不受影响，掩盖了问题。

## 二、修复（纯前端，一处文件）

`TemplatePanel.vue`：

1. 规则摘要单元格 `v-if="t.defaultRules"` 判空，无规则显示"—"
2. `openEdit` 编辑无规则模板时兜底预填 §0 六键默认值（抽 `DEFAULT_RULES` 常量，新建/编辑共用）——避免规则编辑器以 0/false 起步被误保存

## 三、验证

- curl：登录 admin → `GET /api/contest-templates` 返回 401 模板 `"defaultRules":null`（复现输入）
- 浏览器（admin）：模板列表渲染出 401 行（摘要"—"、被引用 1）；**新建模板弹窗正常弹出**（规则预填 3/1/2）；**编辑弹窗正常弹出**（名称回显、规则兜底预填）；取消可关闭
- `vue-tsc` 绿；全前端 grep 仅此一处裸取 `defaultRules.`，无同类隐患

## 四、报备（B 线）

- **种子数据缺口**：`R__demo_data.sql` 模板 401 未插 `code/category/description/default_rules`（全 NULL）。前端已兜底；如需种子模板展示完整默认规则，建议 B 线给 INSERT 补六键 JSON（公共文件，改前群里报备）
- 后端 T02 创建接口 `defaultRules` 可空（null 直接落库），任何 API 创建的无规则模板都会走到前端这个兜底。若 B 线认为 T01 契约应保证 `defaultRules` 为非空对象，需在接口清单明确并后端补默认值
