# 2026-10-19 B 线修复：比赛列表行距参差

> 报障：比赛管理 → 比赛列表，各条比赛的行间距不一样（有的行高有的行矮）。
> ⚠️ 本修复跨到 B 线模块（比赛管理前端），由组长直接指派，开 PR 时一并报备。

## 一、根因（浏览器 DOM 实测定位）

表格是内容驱动布局（`table-layout: auto`），"报名起止 / 比赛起止"两列显示**完整时间段**（`2026-10-18 00:00:00 ~ 2026-10-22 23:59:59`），每列内容宽 ~300px；"名称"列是唯一不定宽列，被两列挤到 **60px**——比赛名（14 字级别）在 60px 里折成 2~6 行，实测行高 **61 / 84 / 124px** 三种，视觉上行距参差。

## 二、修复（纯前端，一处文件）

`CompetitionPage.vue` 三件套：

1. **列表起止显示到日 + 同年省略右端年份**：新增 `rangeOf()`，`2026-10-18 00:00:00 ~ 2026-10-22 23:59:59` → 显示 `2026-10-18 ~ 10-22`（跨年则右端带年份 `2026-12-01 ~ 2027-01-15`；未填显示 `— ~ —`）。完整时分秒在详情抽屉仍可见——与项目列表"起止到日"同口径
2. **表格固定布局**：`cols-fixed`（`table-layout: fixed`），列宽只认 thead 设定——学期 170 / 状态 80 / 报名·比赛起止各 165 / 赛道·赛队各 44 / 操作 60，名称列拿剩余宽度（1280 视口实测 ~191px），内容不再挤列
3. **名称单行省略兜底**：`td.name-cell` 单行 + `text-overflow: ellipsis` + 悬停 `title` 全名——超长名（后端上限 200 字）也保证单行、行高恒定，悬停和详情抽屉可看全名

## 三、验证

- 浏览器实测（admin，1280 视口）：修复前行高 61 / 84 / 124 → 修复后**短名 / 14 字长名 / 46 字超长名（省略号截断）行高统一 61.5px**（末行 60px 是全站 ledger `tr:last-child` 无下边框 2px 的既有统一样式，非本页问题）
- 超长名兜底：46 字名称 scrollWidth 670px → 截到 191px 单行省略号，`title` 悬停有全名，行高不变
- 同年省略格式：`2026-10-18 ~ 10-22`；未填日期：`— ~ —`
- `vue-tsc` 绿；验证用临时比赛已删除（列表恢复原 2 条数据）

## 四、报备与口径说明

- B 线文件 `CompetitionPage.vue`（组长指派修）
- **列表时间显示口径变化**：起止列从"完整时分秒"改为"到日 + 同年省略"。若要求列表恢复完整时间，需砍掉学期/状态列或加宽面板，代价更大；完整时间始终在详情抽屉可查
