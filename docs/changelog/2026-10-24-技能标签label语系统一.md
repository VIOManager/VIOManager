# 2026-10-24 技能标签 value-label 分裂修复（后端）

> 现象：8090 真模式保存成员技能报"技能标签不在字典中：Java 开发"，但词条刚在系统配置新增成功且下拉可选。
> 定位：前端会话（三层链条的第三层，前两层前端已修）——后端 M12 校验按 itemValue 收键，
> 前端全链路（下拉/提交/回显/筛选）提交的是 itemLabel；库存量条目"值=名"碰巧一致没炸，
> lzh 新建"Java 开发"（值≠名）首次暴露。
> 方案：`.agentdocs/plans/2026-10-24/技能标签value-label分裂-修复说明.md`

## 修复（A 线 person 模块，收键一处 + 注释同步）

`PersonCommandSupport.availableSkillLabels()` 的 `Collectors.toMap` 收键从 `getItemValue` 改为
`getItemLabel`（键=值=label）——校验、落库、回显、筛选整条链统一 label 语系：

- 校验：提交 label → map 键 label → 命中
- 落库：skill_value 与 skill_label 同存显示名
- 回显：M01/M02 读 skill_value → 返回显示名直接渲染
- 筛选：M01 skill 参数（label）对 skill_value（=label）→ 命中
- **存量自愈**：值=名的老条目两列同串不受影响；lzh 那条"Java 开发"修复后直接可用

已知代价（记录在案）：SY04 给词条改名后，已存技能串不跟随（显示旧文案，重新保存才更新）。
