# 2026-10-16 PM 修复：节点提交审核误报 1001（无档案超管被拦）

> 报障：比赛节点「提交审核」点了没反应。实际是确认弹窗后接口回 `1001 参数校验失败`——提示无信息量，节点停留草稿，体感"没反应"。

## 一、根因

`MilestoneServiceImpl.submit`（PR20）在提交人无人员档案时直接抛 `CommonErrorCode.PARAM_INVALID`（1001）。审批单 `approval.applicant_id` **表结构 NOT NULL**——提审必须落到具体人员名下，无档案的超管 admin 账号走不下去。逻辑本身是契约决定的（表结构不可改），错在**错误码误导**：与 7013（创建项目同款问题）一个病根。

## 二、改动

| 文件 | 改动 |
|------|------|
| `vio-common/.../ProjectErrorCode.java` ⚠️公共文件报备 | + `MILESTONE_APPLICANT_NO_PROFILE(7014)`：明确文案「当前账号未绑定人员档案，无法提交节点审核（审批单须落在具体人员名下）；请由绑定档案的部门管理员提交，或为本账号绑定人员档案」 |
| `MilestoneServiceImpl.submit` | 1001 → 7014（原逻辑不变：表结构约束仍在） |
| `MilestoneTest` | + `profileLessSuperAdminCannotSubmitButOthersCan`：无档案超管 7014 且节点停留 DRAFT；无档案部门管理员同理；有档案管理员提交同节点 0 → PENDING（对照） |
| `docs/api/项目管理-前端对接清单.md` | §8 错误码表 + 7014；§8.1 补 PR20 提交人须有档案的边界说明 |

前端零改动（http 层错误 toast 本就工作，此前弹的"参数校验失败"无信息量）。

## 三、验证

- 单测：MilestoneTest 6/6，PM 全套 **51/51** 绿

- 浏览器：admin 点「提交审核」→确认→ toast 弹出 7014 完整文案（不再是"参数校验失败"）
