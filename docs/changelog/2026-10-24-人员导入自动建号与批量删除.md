## M07 行为（拍板口径）

- 建号规则完全复用 M13：登录名 = 学工号 → 学号（模板两值同列）、abc123、default_password=1 首登强制改密
- 学号已存在且有账号 → 跳过（重导幂等，不计成功不计失败）
- 学号已存在但无账号 → **只补建账号**（重导补 M13 漏绑的存量），计入 successCount
- 建号失败（登录名被占 / 行内无学工号）→ 整行失败：**行级事务回滚档案**，errors 带行号原因——不留"有档无号"半成品
- 部门管理员补号限档案真实组织在自己子树内（不信 Excel 行里的组织列）

## M05B 行为（整批拒绝）

- 任一 id 不可删 → **全批不动**，message 列名单（"整批未删除，不可删——张三：队长…；李四：当前登录账号"）
- 逐 id 规则同 M05：不存在 1004 / 越权 1003 / 队长 3003 / 本人 3004；超上限 200 → 3011
- 全批可删 → code 0，级联同 M05 单删（逻辑删档案+物理删技能+清队伍关系+禁用账号）；重复 id 去重
