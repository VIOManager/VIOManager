# 更新说明：项目管理模块——管理员权限放开（权限最高，可执行所有操作）

> 日期：2026-10-16 ｜ 分支：feature/pm ｜ 决策：组长拍板（原清单 §5 待确认③「仅所有人从严」口径**作废**）
> 范围约束：仅项目管理模块（backend `com.viomanager.project` + `ProjectErrorCode` + 前端 PM 页面与 mock）；**零数据库结构变更**（`initsql.sql` 未动，`project_task.completed_by` 本就可空，无需改表）

## 一、拍板内容

管理员（超级管理员 + 部门管理员）在项目管理模块内**权限最高，可执行所有操作**：

| 写口 | 原口径（仅所有人 7002） | 新口径 |
|------|------------------------|--------|
| PR04 编辑项目 / 状态流转 | 仅所有人 | 所有人 **or 管理员** |
| PR05 删除项目 | 仅所有人 | 所有人 **or 管理员**（7010 挂载拦截保留） |
| PR07/PR08 加/移成员 | 仅所有人 | 所有人 **or 管理员** |
| PR09/PR10 加/移指导教师 | 仅所有人 | 所有人 **or 管理员** |
| PR22 创建任务 / PR24 删除任务 | 仅所有人 | 所有人 **or 管理员** |
| PR23 编辑任务 | 所有人全字段；负责人仅置 DONE | 所有人/管理员全字段；负责人仅置 DONE（不变） |
| PR26 上传文件 | 所有人与成员 | 所有人/成员/**管理员**（管理员须有人员档案） |
| PR27 删除文件 | 所有人删任意；成员删自己 | 所有人/**管理员**删任意；成员删自己 |
| PR30/PR31 授权列表/撤销 | 已是所有人或管理员 | 不变（判定逻辑收口统一） |

**部门管理员的管辖边界**：项目所属组织在其管辖子树内才可操作（与可见性第 4 条同款口径——"能看就能管"）；跨子树的部门管理员依旧 7002。超管不限范围。

## 二、保留的业务边界（未放开，防数据语义破损）

1. **赛队挂载/解绑（PR13/PR14）仍是队长职权**——挂载是赛队侧发起的动作，不随本口径放开
2. **成员表 OWNER 行不可移除**——所有人/管理员都不能移（移了项目无主）
3. **上传须有人员档案**——`project_file.uploaded_by` 落库依据；admin 超管账号无档案，上传报 7013（与创建项目同码）
4. **PR30/PR31 非门槛者错误码沿用 1003**（HTTP 403）——历史契约，仅内部判定逻辑收口，不改码
