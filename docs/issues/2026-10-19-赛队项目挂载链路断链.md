# 问题记录：赛队与项目管理信息不匹配 / 挂载池为空（PM 挂载链路断链）

> 记录日期：2026-10-19　状态：**已定位，修复方案待组长确认**（方案要点见 §四）
> 影响模块：项目管理（组长侧）；赛队管理仅受牵连展示，无代码问题
> 发现路径：组长以普通用户（stu_wang）联调时先后发现两处现象，实为同一条断链

## 一、现象

1. **赛队信息与项目管理不匹配**：stu_wang（王小明，member 103）的赛队管理有 3 支队（123 / qweqwe / 代码先锋队，均挂第十六届蓝桥杯，且组队时填了"项目名"），但项目管理页显示"暂无可见项目"（0 条）
2. **挂载下拉为空**：赛队详情抽屉 →"挂载项目"面板 → 下拉选择器里没有任何可挂载项目

## 二、复现步骤

1. stu_wang 登录 → 赛队管理：能看到 3 支队（列表"项目名"列有值）
2. 项目管理：0 个项目
3. 任一队的详情抽屉 → 挂载项目面板：'暂未挂载项目'，下拉无可选项
4. admin 登录佐证：`GET /api/projects` 全平台 total=0——库里根本没有任何项目

## 三、根因（三层）

**前置说明（设计如此，不是 bug）**：赛队列表的"项目名"列是组队申请时填的**文本意向**（`team.project_name`），建队审批回调只建队+队长+预填成员，不创建项目——PRD §3.10 定义的"项目独立于赛队"。真正的关联要靠**挂载**（队长把已存在的项目挂到队上，挂载后比赛节点任务同步 PR17 才生效）。

断链发生在挂载链路的 UI 两端：

| # | 断点 | 证据 |
|---|------|------|
| 1 | **库里 0 个项目**——从来没人通过 UI 建过（审批中心演示单里的"智能小车竞速"是 mock payload，非真实数据） | admin 实测 `GET /api/projects` total=0 |
| 2 | **项目创建弹窗没有"关联比赛"字段**：`ProjectPage.vue` 表单仅名称/描述/可见性/起止。后端 PR02 DTO、create()/update() 落库（ProjectServiceImpl:132/218）、前端 mock **全都支持** contestId/trackId，唯独 UI 没暴露 → UI 建出的项目 `contest_id` 恒 NULL | 代码比对三方 |
| 3 | **挂载池按比赛硬过滤**：PR15 `TeamProjectServiceImpl.attachable()` 的 `contest_id = 队伍比赛` 条件把 NULL 项目的项目全部排除。而后端 `attach()` 真实校验只有**队长身份 + 项目可见 + 同学期(7008)**，并不要求项目关联同一场比赛 | attach() 源码；curl 复现 |

三层叠加的结果：**学生"建队 → 建项目 → 挂载 → 节点任务同步"链路在 UI 上完全走不通**；PRD §3.10 的通用项目场景（"某学生的 Python 工具项目，可挂到不同赛队/不同赛道参赛"）当前不可实现（通用项目 contest_id 为 NULL，进不了任何队的挂载池）。

## 四、修复方案（待组长确认后实施）

只改项目管理域，**B 线零改动**，无表结构变更：

1. **后端池子放宽**（`TeamProjectServiceImpl.attachable()` 一处）：contestId 过滤从"只放行关联该比赛的"改为"`contest_id = 该比赛 OR contest_id IS NULL`"——对齐 attach 的真实校验与 PRD 通用项目场景
2. **前端创建弹窗补"关联比赛"下拉**（可选，不选=通用项目）：后端字段全就绪，仅补 UI；列表"关联比赛"列随之有值

配套：TeamProjectTest +1 用例（未关联比赛项目进池/可挂载）、mock 同口径、接口清单 PR15 行修订、changelog。修后学生链路全通且全程无需管理员参与（管理员代建只是可选通道）。

完整方案文档（组长本地）：`.agentdocs/plans/2026-10-19/项目管理-挂载链路修复方案.md`
