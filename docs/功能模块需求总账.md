## 二、分模块需求详情

### 3.1 认证与账号（组长 · 2xxx 码段）
- **范围**：登录/改密/本人档案；JWT 主站签发、论坛共享验签。
- **已交付**：`/api/auth` 3 端点（登录、改密、my-profile）；LoginPage；防爆破阈值；CORS 修复（PR#39）。
- **缺口**：① 契约仍是《骨架暂定》§1 未转正录入 Apifox；② my-profile JdbcTemplate 直查待重构注入 OrgService（开发记录待办）；③ 观察项 S-M1 时间格式不统一、S-M2 非 multipart 上传报 1000。

### 3.2 人员档案（A 线 · 3xxx）
- **已交付**：M01-13 全量 16 端点；Excel 导入；证件照/签名走文件服务；隐私脱敏（idCardLast4）；PR#36 人员返工。
- **缺口**：无重大（A 线自查 MP 隐式全列查询清单即可）。

### 3.3 组织管理（A 线 · 3xxx）
- **已交付**：O01-06 全量；组织树缓存预热（O3 9² 千次前缀比较 → warmAll + 8 分钟续温）。

### 3.4 学期管理（A 线 · 3xxx）

- **缺口**：① 拼装指标 vs PRD 三端 HUD 清单（队伍/成果/待办/材料状态/本周绩效）未逐项对账；② 无聚合端点，五路请求随数据量线性放大——量大后建议落一个 `GET /api/stats/overview` 聚合接口（可缓存）。
