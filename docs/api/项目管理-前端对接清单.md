## 0. 通用约定（先读这个）

| 项 | 口径 |
|----|------|
| 响应形态 | `{code, message, data}`；`code=0` 成功，非 0 业务码 |
| **Long 一律字符串** | 雪花 ID（id/fileId/total 等）全局序列化为字符串，前端用 String 接，**不要 Number 强转**（超 JS 安全整数丢精度） |
| **1003 = HTTP 403** | 仅 1003（权限不足）映射 HTTP 403；其余业务码都是 HTTP 200 + code。axios 拦截器要同时处理 403 响应体里的 code |
| 幂等头 | 全站暂未挂 @Idempotent（前端未带 `X-Idempotency-Key`）；**审批接口（/api/approvals/*）必须带头**，PM 自己的接口不用 |
| 时间格式 | `yyyy-MM-dd HH:mm:ss`（@JsonFormat 统一） |
| 错误码段 | 7xxx 项目域（见文末表）；1xxx 通用（1001 参数 / 1003 权限 / 1004 不存在 / 1006 状态 / 1007 并发冲突 / 1010 染毒 / 1011 扫描服务不可用） |

## 1. 项目列表/详情（ProjectPage）

| 接口 | 说明 |
|------|------|
| `GET /api/projects` | PR01。query：keyword/status/contestId/semesterId/orgId/page/size。**数据范围自动**：学生=参与的∪授权的（ORG 项目不进学生列表，只影响详情可达）；部门管理员=本子树；超管全部 |
| `GET /api/projects/{id}` | PR03 详情。**ONCE 授权在此消耗**：用完即失效（刷新页面会 7003，引导改申请 LIMITED） |
| `POST /api/projects` | PR02。body：name（必填 ≤200）、description、contestId、trackId、semesterId（默认当前学期）、orgId（默认本人组织）、visibility（默认 ORG，PRIVATE/ORG/PUBLIC）、startDate、endDate、remark |
| `PUT /api/projects/{id}` | PR04。带 `updatedAt`（详情回显值）做乐观锁；status 只能 ACTIVE→FINISHED→ARCHIVED 按序 |
| `DELETE /api/projects/{id}` | PR05。有挂载中的赛队 7003 拒绝（先解绑） |

## 2. 成员与指导教师（DetailDrawer）

- `GET /api/projects/{id}/members`：列表含 OWNER 行（建项目自动生成，角色回显）
- `POST /api/projects/{id}/members`：body `{memberId}`；重复 7005
- `DELETE /api/projects/{id}/members/{memberId}`：OWNER 行不可移除（7002）
- `POST /api/projects/{id}/advisors`：body `{memberId, title?}`；非教师类型 7006
- `DELETE /api/projects/{id}/advisors/{memberId}`
- ⚠️ **教师没有列表接口**（清单未设，接口先行不自造）——详情页教师展示待正式需求，当前只能靠添加记录本地回显

## 3. 赛队挂载（ProjectPage 挂载选择器 / 赛队详情页）

- `GET /api/projects/attachable?contestId=`：PR15 挂载池（PUBLIC ∪ ORG同部门 ∪ 自己参与）
- `POST /api/teams/{teamId}/projects`：PR13。body `{projectId, trackId?}`；仅队长（1003）；同学期 7008；同队同项目同赛道 7007
- `DELETE /api/teams/{teamId}/projects/{projectId}`：PR14 解绑；任务不回收
- `GET /api/projects/{id}/teams`：PR11 项目侧（谁挂了我）
- `GET /api/teams/{id}/projects`：PR12 赛队侧（我挂了谁）；字段 projectStatus/mountStatus 分列

## 4. 时间节点（MilestonePanel）

- `GET /api/contests/{id}/milestones?status=&nodeType=`：PR16。**学生只回 APPROVED**；部门管理员限本子树比赛
- `POST /api/contests/{id}/milestones`：PR17。仅部门管理员与超管。nodeType 四值：REGISTER_START/REGISTER_END/WORK_SUBMIT/OTHER
- `PUT /api/milestones/{id}` / `DELETE /api/milestones/{id}`：仅 DRAFT（REJECTED 可编辑）；7009
- `POST /api/milestones/{id}/submit`：PR20 提审 → 审批中心 MILESTONE_APPROVE 单（审批人=超管或比赛归属组织的管理员）
- 通过后自动：挂载该比赛的 ACTIVE 项目批量生成任务（title=节点名，due_date=节点时间）

## 5. 任务（TaskPanel）

- `GET /api/projects/{id}/tasks?status=&assigneeMemberId=`：PR21，按 sort_no 排序；`milestoneNodeId` 非空=节点同步任务
- `POST /api/projects/{id}/tasks`：PR22 手工任务。title 必填；priority 默认 NORMAL（HIGH/NORMAL/LOW）
- `PUT /api/projects/{id}/tasks/{taskId}`：PR23。**所有人改全部字段；负责人本人只能 `{status:"DONE"}`**（带其他字段 7002）
- `DELETE /api/projects/{id}/tasks/{taskId}`：PR24；同步任务也可删（删后不自动重建）

## 6. 文件（FilePanel）

- `GET /api/projects/{id}/files`：PR25
- `POST /api/projects/{id}/files`：PR26。multipart：`file` + `fileCategory`（DOC/IMAGE/CODE/OTHER，默认 DOC）+ `remark?`。**所有人与成员可传**（教师不可）
- `DELETE /api/projects/{id}/files/{fileRecordId}`：PR27。**注意删除用关联行 id（列表项 id），不是 fileId**；成员只能删自己传的
- `GET /api/projects/files/{fileRecordId}/download`：PR28。可见性先于文件（项目不可见 7003）；ClamAV 不可用时照常上传下载（scanStatus=UNAVAILABLE）

## 7. 查看申请与授权（DetailDrawer 申请入口）

- `POST /api/projects/{id}/view-requests`：PR29。body `{grantType: "ONCE"|"LIMITED", expireAt?}`；LIMITED 必填 expireAt 且须未来时间；已有 PENDING 7011
- `GET /api/projects/{id}/view-grants`：PR30。仅所有人与管理员（学生 1003/HTTP 403）
- `PUT /api/view-grants/{id}/revoke`：PR31。PENDING/ACTIVE 可撤；终态 1006
- 生命周期：PENDING →（审批通过）→ ACTIVE → ONCE 详情消耗 EXPIRED / LIMITED 到期失效 / REVOKED；驳回 → EXPIRED

## 8. 错误码速查（7xxx）

7001 项目不存在｜7002 仅所有人可操作｜7003 无权查看｜7004 同学期同组织重名｜7005 已是成员/已挂名｜7006 指导教师须教师类型｜7007 已挂载｜7008 学期不一致｜7009 节点状态不允许｜7010 有挂载中赛队先解绑｜7011 已有待审批申请｜7012 任务不存在或不属于该项目
