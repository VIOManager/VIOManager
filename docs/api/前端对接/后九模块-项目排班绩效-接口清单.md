## 1. 项目管理（7xxx）

- **可见性八条**（§2，所有读接口共用）：所有人 → 成员/指导教师 → 超管全部 → 部门管理员子树 → PUBLIC → ORG 同部门 → ACTIVE 授权 → 7003
- 写操作一律**仅项目所有人**（7002）；成员/指导教师直加**不走审批**
- 赛队挂载：队长操作（PR13/PR14），同学期校验（7008）；PR12/PR11 互为镜像
- 比赛节点：DRAFT →（PR20 提交）→ PENDING（开 MILESTONE_APPROVE 审批单）→ 通过后**自动给挂载该比赛的 ACTIVE 项目生成任务**；REJECTED 可改后重提
- 任务：所有人全字段编辑；负责人本人仅可置 DONE（completed_at/by 回填）
- 文件：先走骨架 F01 上传拿 fileId，再 PR26 关联（幂等）；下载 PR28 先校验可见性再转发（mock 回提示）
- 查看授权（PR29–PR31）：ONCE 看一次详情即消耗 / LIMITED 到期失效；申请走 PROJECT_VIEW 审批单（审批责任组织=项目所属组织）；7011 防重复申请
- **清单缺口（待后端补）**：指导教师无独立列表读接口，暂挂 PR03 详情扩展字段 `advisors`（前端已按此消费）

## 2. 排班管理（8001–8039）

- 课表三步：TT02 上传**同步解析**（拍板）→ 班级映射确认（**未确认班级永远不参与空课统计**）→ SC06/SC07 空课查询（单双周计入：ODD 奇周占用/EVEN 偶周占用）
- TT05：学期名归一化失败的批次留 PENDING，人工指定学期后续跑
- 排班校验链（SC02/SC03 按序）：8009 非本子组织 → 8007 时段未启用 → 8006 超人数上限 → **8005 同周同人同子组织仅一条**（拍板，服务层兜底唯一键缺口）→ 8008 课表冲突（前端弹确认后带 `force` 重提，打冲突标记）
- SC02 带幂等头；SC01 周排班表部门管理员仅本子树；SC05 我的排班（学生）
- 规则（SC10/SC11）：子组织维度 7×5 时段开关 + 人数上下限；学期特定规则优先、回退默认

## 3. 绩效统计（8040 起）

- **不走审批中心**（PRD §3.13 管理员直审，打分即审核）
- 周报状态机：SUBMITTED → SCORED / REJECTED；驳回不删记录，改后原记录重进待审核；同人同周同子组织仅一份（8041）
- 打分（PF07）：维度集合须与该子组织启用规则完全一致（8043）、不超满分（8044）、未配置规则 8046；**权重/满分随打分时点落快照**，规则变更不回溯历史分
- 加权总分 = Σ（得分 × 权重快照）；打分事务内重算学期汇总 + 子组织内排名 + 近 4 周趋势斜率
- 内置标签（§4）：活跃度上升/下降（斜率）、功劳度高（子组织前 20%）、连续贡献（≥4 周）、高效周（单周 ≥ 满分 90%）
- PF02/PF07 带幂等头；管理侧列表/汇总部门管理员按子树裁剪
