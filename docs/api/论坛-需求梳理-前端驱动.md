需求来源：lzh 2026-10-23——"点赞收藏没有能看到的地方、个人没有创作的地方"。

身份口径：**服务端按 JWT userId 过滤，不收前端传人**。响应形状已在前端 `api/me.ts` 固化：

| 建议编号 | 端点 | 响应 | 口径 |
|----------|------|------|------|
| F15 | `GET /api/forum/me/topics` | `TopicItem[]`（复用 F01 列表项形状）| 本人发的帖，新帖在前 |
| F16 | `GET /api/forum/me/replies` | `MyReplyItem[]`：`{topicId, topicTitle, floorNo, text, publishAt, likeCount}` | 本人在各帖的楼层，**附所属帖标题**（跳转用）|
| F17 | `GET /api/forum/me/collections` | `{topics: TopicItem[], techPosts: TechPostItem[]}` | 收藏两路合并：论坛帖 F09 + 技术推送 T03（后者依赖 §五.1 拍板）|
| F18 | `GET /api/forum/me/likes` | `{topics: TopicItem[], replies: MyReplyItem[]}` | 点赞两路合并：帖 F08 + 楼层 F10 |

实现要点：
- **零表结构变更**——全部由现有 `forum_topic / forum_reply / forum_topic_like / forum_topic_collect` 查询可得（MePage 头卡"获赞总数"由前端从四列表汇总，无需额外接口）。
- 前端当前**无分页参数**（演示量全量拉取）；若正式量级需要分页，需与前端同步改 shape（决策点 §五.3）。
- 需定口径：HIDDEN 帖/楼层在"我的"列表中如何呈现（详见 §五.2）。

### 5.2 个人中心的 HIDDEN 口径

"我的主题/回复/收藏/点赞"列表中，被管理员隐藏（HIDDEN）的内容如何呈现：
- 对**内容本人**展示原文还是占位？（主站楼层侧的 M2d 口径是"对学生与管理员都 9102 不可见"，但那是详情页；个人中心列表是新场景）
- 收藏了后来被隐藏的帖，收藏列表里显示什么？
建议：本人维度同 M2d 占位处理 + 行内"已隐藏"徽章（与首页管理档视觉同款），拍板后写入清单。

### 5.3 me 系列分页

前端现按全量数组消费（演示量 <百条）。若预期上千条需改为 PageResult 并同步改前端；建议首版就按 PageResult 落（成本相同，免二次返工）。

### 5.4 生产环境跨站登录交接 ~~⭐ 上线阻塞~~ **已拍板关闭（2026-10-23）：不同意，维持现状**

### 5.5 换头像上传

`MeAvatarDialog` 现仅存 localStorage（换端即失）。正式方案两选一：
- 走主站文件服务（`member.photo_file_id`，头像属人员档案，主站域）——需协同；
- 论坛库自建（forum_user.avatar 列）——论坛域自治，但与主站头像两套口径。
涉及跨域职责边界，建议与组长对齐后定。
